# Codice di condotta

Edomea Marketplace è aperto a tutti. Chi partecipa (issue, discussioni, pull request, revisioni) si impegna a:

- trattare le altre persone con rispetto, indipendentemente da esperienza, provenienza, genere, età, religione, orientamento o disabilità;
- criticare il lavoro e le idee, mai le persone;
- non usare linguaggio offensivo, molestie, minacce o contenuti sessuali;
- non pubblicare dati personali altrui, credenziali o dati reali di clienti e negozi;
- accettare che le decisioni finali sul progetto spettano al titolare.

Comportamenti contrari possono portare alla rimozione dei contenuti e all'esclusione dal progetto.

Per segnalare un comportamento scorretto usa la segnalazione privata della scheda **Security** oppure contatta il titolare tramite il profilo GitHub [edomea](https://github.com/edomea).
