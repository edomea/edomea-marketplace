Chiave dei backup

      
Una sola chiave cifra tutti i backup di questo server, sul server e sulla destinazione remota. Senza la chiave non si
        possono ripristinare su un'altra macchina: conservala fuori da qui (gestore di password, foglio in cassaforte).

      

      

      


      

        
Collega una destinazione

        

          
          
          
        

        
EMP vede solo i file che crea lui, nella cartella EMP-backup del Drive.
          Dopo "Collega" si apre Google: accedere con l'account dei backup e consentire l'accesso.

        

          Client Google proprio (facoltativo)
          
Di solito non serve: lasciare vuoto. Serve solo se avete un progetto su Google Cloud con un client OAuth
            di tipo App desktop e l'API Google Drive attiva. Attenzione: EMP vede solo i file creati con lo
            stesso client, quindi passando da un client all'altro i backup già sul Drive non compaiono più nell'elenco.

        Cosa contiene il backup
        
Tutto EMP e solo EMP: database, Core, plugin, cataloghi e il pacchetto della versione di EMP Server in uso. Non contiene ciò
          che appartiene alla macchina (nome, certificato HTTPS, collegamento a GitHub e alla destinazione remota). Prima di ogni
          aggiornamento di EMP Server il backup si fa da solo. Da console: sudo emp-server backup-decifra FILE USCITA crea
          una copia in chiaro, sudo emp-server ripristina FILE --chiave CHIAVE ripristina il backup di un altro server.
