← Amministratore Tecnico

Da questa pagina si installano i plugin dell'ecosistema EMP. Il Core li installa nell'ordine delle dipendenze; i pacchetti provengono dal catalogo di EMP Server o da quelli caricati qui, e sono verificati con la loro impronta SHA-256.

Funzione riservata all'Amministratore Tecnico, disponibile solo con l'indirizzo https://.

Nessun catalogo configurato: indicare catalog_dir o local_catalog_dir nella configurazione del Core.

Carica un pacchetto

Pacchetto ZIP del plugin (una cartella con il nome del plugin e il suo emp-module.json), massimo 64 MB. Il pacchetto entra nel catalogo locale; poi si installa dall'elenco. Funziona anche senza Internet.

Da GitHub (facoltativo)

Importa nel catalogo locale i plugin di una release pubblicata del repository indicato (bozze e pre-release escluse). Serve Internet solo al momento dell'importazione; disattivata, EMP non contatta GitHub.

Estensione PHP curl assente: rieseguire l'installazione di EMP Server.
