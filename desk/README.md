# Edomea Desk

Applicazione nativa per Windows, macOS e Linux, scritta in **Rust**, con modalità **Server** (installa web server, PHP, MariaDB e Core) e **Client** (si collega al server in LAN tramite le API del Core).

Specifiche: [manuale tecnico-operativo](../docs/manuale-tecnico-operativo.md), sezioni 02, 03 e 09.
