Installa sul computer MariaDB, PHP e il web server Caddy come servizio di Windows EMP Server, che parte da solo all'accensione, e il Core di EMP. Tutto risponde solo da questo computer (accesso dalle casse in LAN: Macro 3).

Windows chiederà la conferma dei permessi di amministratore. I dati esistenti non vengono mai cancellati.
