2. EMP Core

EMP Desk installa solo il Core, incluso in questo installer. Il pacchetto è verificato con la sua impronta SHA-256 prima dell'installazione.

Gli altri plugin (cassa, magazzino, Studio, contabilità…) si installano dopo, dalla pagina Plugin dell'interfaccia web del Core.

3. Avvio del Core e amministrazione

Modalità laboratorio: PHP incluso in Desk, database SQLite, Core raggiungibile solo da questo computer finché EMP Desk resta aperto. Nginx, MariaDB e l'avvio automatico come servizio arriveranno con la Macro 2.
