# emp-fornitori-espo — Ricambi ESPO/ASWO

**Stato:** previsto · **Deriva da:** edomea-espo

## Scopo
Lettura dei DDT PDF del fornitore (descrizione, quantità, prezzo d'acquisto), schede prodotto raccolte dall'estensione browser, nuovi articoli con EAN generato dal Core e file di carico per il magazzino.

Alimenta il magazzino solo tramite le API di `emp-magazzino`.

## Dipendenze previste
- `emp-core`, `emp-studio`, `emp-magazzino`
