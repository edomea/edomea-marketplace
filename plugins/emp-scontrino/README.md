# emp-scontrino — Registratore telematico

**Stato:** previsto, priorità P0 · **Deriva da:** edomea-scontrino

## Scopo
Emissione di scontrini tramite il servizio scelto per i registratori telematici (Effatta, multi-negozio), registro in sola aggiunta, distinzione tra reso e annullo, pagamenti contanti/carta/misto/finanziamento.

**Collaudo fiscale obbligatorio** prima dell'uso reale.
