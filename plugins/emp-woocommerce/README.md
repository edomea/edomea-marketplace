# emp-woocommerce — Canale web

**Stato:** previsto · **Nuovo** (EMP Web)

## Scopo
Collega il negozio online WordPress/WooCommerce al Core tramite API: pubblicazione dei prodotti autorizzati, disponibilità per negozio o aggregata, ricezione degli ordini.

WooCommerce è un **canale**, non il gestionale: catalogo e giacenze restano nel Core e nei plugin EMP.

## Dipendenze previste
- `emp-core`, `emp-studio`, `emp-magazzino`
